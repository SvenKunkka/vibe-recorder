# Changelog

## v1.0.0 — 2026-11-13

Initial open-source release of Vibe Recorder / Vibe 录音库.

- Record the default microphone as mono 16-bit PCM WAV, preserving pauses.
- Save completed takes automatically to a browser-local recording library.
- Play previous recordings and download WAV files from the same page.
- Show the actual input name and reconnect after changing default devices.
- Preserve unsaved audio when library storage fails, with a save retry.
- Provide a self-contained HTML build and a local-only Python server.
- Include Chinese and English documentation, MIT licensing, and audio/library checks.
