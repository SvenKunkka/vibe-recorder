# Vibe Recorder

一个轻量的浏览器录音工具：录下一段，自动保存在本机，随时回听并下载 WAV。

[English](README.en.md) · [下载单文件版](https://github.com/SvenKunkka/vibe-recorder/releases/latest/download/Vibe-Recorder.html) · [MIT 许可证](LICENSE)

界面目前为中文。项目不需要账号、云服务或 npm 依赖。

## 能做什么

- 使用浏览器的默认麦克风录音，显示实际接入的设备名称。
- 输出 **16 位 PCM、单声道 WAV**，采样率以浏览器实际建立的音频上下文为准。
- 保留停顿和静音，不做自动裁剪、归一化或语音识别。
- 停止后自动保存到浏览器本地录音库；点击历史录音即可回听，也可逐段下载 WAV。
- 显示录音时长、输入电平与波形；回放时点击波形可定位。
- 自动保存失败时保留当前录音，提供下载和重试保存；设备断开或音频中断时尝试保留已收到的部分。
- 每段最长约 **30 分钟**，到达上限自动停止；日常建议每段控制在 10 分钟内。

## 快速开始

### 单文件版

从 [最新 Release 下载 Vibe-Recorder.html](https://github.com/SvenKunkka/vibe-recorder/releases/latest/download/Vibe-Recorder.html)，使用较新的 Chrome 或 Edge 打开。该文件包含页面、样式和录音代码，不需要安装 Python 或 Node.js。

直接以 `file://` 打开时，麦克风权限、AudioWorklet 和本地存储的行为因浏览器而异；本项目尚未直接验证此方式的完整录音流程。如果无法使用，请采用下面的本机网页入口。

### 从源码启动本机网页

需要 Python 3。在项目根目录运行：

```sh
python3 web/server.py
```

然后打开 **[http://127.0.0.1:8771](http://127.0.0.1:8771)**。服务仅监听本机地址，负责提供静态页面，不接收音频上传。保持启动窗口运行；结束后可按 `Ctrl+C` 关闭服务。

仓库还提供 `启动自用录音库.command`（macOS）和 `启动自用录音库-Windows.bat`（Windows）启动入口，同样需要 Python 3。

## 录音与回听

1. 在系统和浏览器设置中选好默认麦克风。
2. 点击「允许麦克风」或「开始录音」，授权后核对「实际录音输入」中的名称。
3. 点击「停止并生成 WAV」，等待页面显示「已保存到录音库」。
4. 从「我的录音」点击历史录音回听，或点击「下载 WAV」另存文件。

页面不提供设备选择列表。切换默认麦克风后，点击「重新连接」再核对设备名称；重新连接会先释放旧输入，再向浏览器请求当前默认输入。正常停止后可继续使用已授权输入；闲置时可以点击「断开麦克风」。

录制期间保持电脑唤醒，不要关闭或刷新页面。录音只有在停止并成功保存后才进入录音库；正在录制的内容不会实时持久保存。

## 录音存在哪里

录音与元数据保存在当前浏览器的 **IndexedDB** 中。应用没有音频上传、转写、账号或云同步功能；本机网页服务器也不接收录音。

- 使用同一浏览器、同一用户配置和同一页面来源，才能访问原有录音库。网页来源由协议、主机名和端口组成。
- 使用本机网页时，请继续打开同一个完整地址。例如 `http://127.0.0.1:8771` 与 `http://localhost:8771`、不同端口或 HTTPS 地址的存储互不共享。
- 更换浏览器、使用无痕窗口、改为打开下载的 HTML，或复制 HTML 到另一台电脑，都不会自动迁移原有录音。
- **HTML 文件不包含录音。** 分享或备份页面文件不会同时分享或备份录音库。
- 清除浏览器网站数据、删除用户配置或浏览器回收存储空间可能使录音丢失；无痕模式通常不会长期保留数据。
- 浏览器配额不足时自动保存可能失败。此时先下载当前 WAV，再按需要重试保存；页面不会用新录音替换已有录音。

**重要录音请另行下载 WAV 并备份。** 浏览器录音库方便日常回听，但不能代替独立文件备份。已有本机网页录音可继续在原浏览器、原配置和原完整地址访问。

## 音频与兼容性说明

应用请求关闭回声消除、降噪和自动增益，并直接将收到的单声道音频转换为 PCM16。浏览器、操作系统、驱动或设备仍可能处理或重采样音频，因此不保证与设备原生采样逐位一致，也不保证固定采样率。

| 范围 | 验证情况 |
| --- | --- |
| macOS 上的 Chrome、本机网页入口 | 已实际验证录音、自动保存与历史回听流程 |
| Windows、Edge、其他浏览器或移动设备 | 尚未进行对应环境的实际录音验证 |
| 下载 HTML 后直接以 `file://` 打开 | 尚未直接验证完整流程；权限和存储取决于浏览器 |
| 自动化测试 | 使用合成音频及模拟浏览器对象，不代表上述平台的实际录音验证 |

录音需要浏览器支持 `getUserMedia`、AudioWorklet 和 IndexedDB，以及可用的麦克风权限。本机回环地址或 HTTPS 是推荐入口。

## 开发与构建

源码无需 npm 安装步骤：

```text
web/                     页面、样式、录音与本地存储模块
Tests/library-flow.mjs   默认输入、重新连接、保存与回听流程测试
Tests/web-audio.mjs      PCM 转换、静音保留和 WAV 格式测试
build-web.py            构建独立 HTML
```

构建单文件版需要 Python 3：

```sh
python3 build-web.py
```

产物为 `dist/Vibe-Recorder.html`，可作为 GitHub Release 附件分发。构建过程仅打包应用资源，不会读取或嵌入浏览器录音。

运行测试需要 Node.js 22 或更高版本：

```sh
node Tests/library-flow.mjs
node Tests/web-audio.mjs
python3 build-web.py
node Tests/check-bundle.mjs
```

音频测试会在 `outputs/` 生成合成 WAV 验证文件；这些测试产物不随发行版提供。
